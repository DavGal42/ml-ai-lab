# PyTorch vs NumPy

И PyTorch и NumPy — это библиотеки для работы 
с многомерными массивами и математическими операциями. 
Однако, PyTorch имеет несколько преимуществ по сравнению с NumPy, 
особенно в контексте машинного обучения и глубокого обучения:

# Главные отличия 

NumPy работает только на CPU.
PyTorch может переносить вычисления на GPU, что ускоряет работу в сотни раз.
Автоматическое дифференцирование (autograd). 
    Это главная суперсила PyTorch. 
    Он сам считает градиенты — это нужно для обучения нейросетей.

# Что такое градиент?

Градиент — это число (или вектор),
которое показывает насколько и в каком направлении быстрее всего изменяется функция.


# Простой пример

Пусть у нас есть функция f(x) = x^2.
Если x = 2, то f(2) = 4.
Градиент в точке x = 2 будет равен 4,
потому что если мы увеличим x на 1, то f(3) = 9,
а если мы уменьшим x на 1, то f(1) = 1.
Таким образом, градиент показывает, что функция растет быстрее всего в направлении увеличения

# Общая формула
# Это называется производная.

f′(x)= f(x+h)−f(x)​ / h

# где h — это маленькое число, например 0.001
Градиент в точке x = 2 
будет примерно равен (f(2.001) - f(2)) / 0.001 = (4.004001 - 4) / 0.001 = 4.001.   
Это означает, что если мы увеличим x на 1, то f(x) увеличится примерно на 4.001.
# Например:
x + 0.01 
функция увеличится примерно на 0.01 * 4.001 = 0.04001
